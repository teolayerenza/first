# Historias

## Lanzamiento (`lanzamiento/`, 1080×1920)

Se suben **el día del lanzamiento, después de los 6 posteos**, en orden. El texto está lejos de los bordes de arriba y de
abajo, que tapa Instagram.

| Historia | Qué agregar al subirla |
|---|---|
| `01.png` Hoy arrancamos | — |
| `02.png` 3.955 cuadras, 0 relevadas | — |
| `03.png` Reportá un pozo | **Sticker de link** a la web, debajo de "Tocá el link." |
| `04.png` Calificá tu cuadra | **Sticker de link** a la web, debajo de "Tocá el link." |
| `05.png` 100% anónimo | — |
| `06.png` Compartilo con tu barrio | Compartir el posteo 1 encima (avión de papel → Agregar a tu historia) |

Las historias **no se pueden programar** desde Instagram; desde Meta Business Suite sí (Crear historia → Programar).

## Destacadas (`destacadas/`)

Tapas para las historias destacadas del perfil, en este orden:

| Tapa | Nombre | Qué guardar ahí |
|---|---|---|
| `1-como-reportar.png` | Cómo reportar | Historias 03 y las placas del posteo 2 |
| `2-calificar.png` | Calificar | Historia 04 y las placas del posteo 3 |
| `3-anonimato.png` | Anonimato | Historia 05 y las placas del posteo 5 |
| `4-informes.png` | Informes | El informe de cada mes (empieza vacía: se crea con el primer informe) |
| `5-arreglados.png` | Arreglados | Cada pozo que se arregla, con antes y después |
| `6-prensa.png` | Prensa | Notas de medios que mencionen el proyecto |

Para crear una destacada: Perfil → **Nuevo** (el círculo con +) → elegir historias → Siguiente → **Editar portada** → subir la tapa.
Las destacadas se arman con historias ya publicadas, así que se crean después del lanzamiento.
